# Quendoris B / full-field restoration (v0.5 candidate)

**Issue:** The first migration of the old B visual prototype into the production static site lost the field **as a page-level composition**. The real uploaded screenshot shows a nearly black solid backdrop and a small bordered logo square. The reference [Pliny B v0.2] had a dark blue-green editorial canvas and an edge-to-edge right-side inversion field, with the headline and visual separated only by an unobtrusive rule.

## Diagnosis, confirmed from the two versions' CSS

- Production v0.4 `.hero-layout` inherited a normal 1240px maximum container, centered with an 85px-ish side inset, a positive grid gap, and a standalone `.identity-field` card.
- `.hero` and `body` used `var(--q-paper)`, a nearly black flat colour in nighttime mode. Only the logo card contained the actual gradient.
- Reference B used a full-viewport two-column `.home-hero` and a right-side full-height `.identity-field`, where the background was a continuous research atmosphere rather than a boxed illustration.
- A separate original inline link colour in the "archive principle" block defeated future light/dark semantics.

## Controlled correction

The release retains exact markup semantics and text, a 420×420 original Quendoris emblem, 6 clock-scoped variations per theme, the Latin Pliny H1 and the historical citation. Only CSS and one obsolete inline HTML style are changed.

Visual changes:
1. Restore `.hero-layout` to **100% available width**, two columns with zero gap, and the field as the right half of the full hero rather than a card.
2. Restore B's nocturnal `#142024` background and compatible blue/green editorial surfaces.
3. Introduce a subtle responsive radial field **behind the Latin quotation**, not exclusively inside the mark.
4. Remove the card border and aspect-ratio constraint on desktop; keep a separating rule and original inversion mask.
5. At mobile widths, stack the field beneath the quote and remove the separating vertical rule.
6. Reproduce B's lime-colour manifesto panel in dark mode and remove the hard-coded inline link colour to restore contrast.

**No claim of a new visual-quality score**. The colours and geometry were derived from the source-coded historical B prototype and the concrete user screenshot, not generated by an image model.

## Verification and release gate

- The original scientific PDF digest and the rest of the historical content remain unchanged.
- SHA256SUMS updates only `dist/index.html` and `dist/assets/atmosphere.css`.
- The offline structural audit now guards the full-bleed layout, background behind the title, at least one mobile collapse breakpoint, and removal of the old inline colour.
- All CDN, analytics, geolocation and remote JavaScript restrictions are retained.
- **Visual browser rendering remains a separate gate**: Chromium in the assistant container is blocked by administration settings. The maintainer should run the site locally on Arch, compare 1440px and 390px screenshots to B, and review all day/night combinations *before deployment*.
- The production site remains on recovered v0.3 after an earlier user-reported unsuccessful v0.4 deployment; this branch does **not** modify that symlink or merge itself into main.
