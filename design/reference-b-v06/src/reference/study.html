RESEARCH / 001 / ALGORITHMS

Implicit Sliding Puzzles

Компактное представление достижимых конфигураций и конструктивная обратная программа для заданной генератором семьи пятнашек. Полный массив клеток не материализуется.

Поле, клеток10¹²
Программа, КиБ662,4
Узлов грамматики5 379

Один зафиксированный конструктивный профиль, не произвольная доска.

Постановка

Начальное состояние — каноническая решённая доска. Генератор строит последовательность допустимых перемещений пустой клетки и применяет её. Обратная последовательность по построению приводит в исходное состояние.

Определение / конструктивная обратимостьB = G(B₀),   G⁻¹(B) = B₀.

Неявное представление

Прямые ходы, обходы прямоугольников и повторения образуют грамматику физических движений. Длину можно вычислять без развёртывания, конкретный ход запрашивать по индексу, а позиции фишек — через обратимые координатные преобразования.

Граница доказательства

Результат гарантирует решение для состояний, сконструированных самим генератором легальными ходами. Он не доказывает аналогичную сложность для произвольной перестановки и не устанавливает оптимальность длины программы.

Воспроизведение

Для небольших досок доступны буквальные проверки ходов и обратимости; для миллионной стороны — адресные и структурные проверки без перечисления всех клеток.
